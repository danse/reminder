# Product

A privacy-preserving note-taker and **personal diary** running entirely
in the browser, with no server and no analytics sent anywhere. Data is
kept on the device (IndexedDB), so it works fully offline and is suited
for private, date-driven journaling.

## Notes

- **Text** notes with markdown formatting (write + live preview).
- **Voice** notes, recorded and played back in the browser.
- **Picture** notes, captured with the camera or uploaded.

## Organisation

- Notes can be grouped into **files** (folders) and tagged.
- The note list is grouped **chronologically by day** (diary-style
  reading), with search across titles, content and tags.

## Analytics

- Basic local analytics, visualised with charts (donut charts, not pie):
  notes by type, notes over time, top tags, storage per type.

## Platform

- **Mobile-only** web app: single pane at a time, with an off-canvas
  drawer for navigation.
- Fully static and **offline-first**: zero network calls, no server.
- Localised in **English and Italian**; UI strings are never hardcoded.
